# Web UI Contract: Castelo do Eco

## Entry and Navigation

- Production entry: the static `index.html` generated by the web build.
- All interface labels, help content, validation messages, chart labels, and empty states are in Portuguese.
- Main navigation exposes prediction, session history, and mathematical documentation; navigation is usable by keyboard and has an announced active state.
- The page remains a single learner experience; there is no login, teacher view, shared session, or account navigation.

## Prediction Form

- One labeled multiline or single-line text field accepts the same grammar as the Fase 1 CLI:
  - comma-separated integers, e.g. `3, 6, 9, 12`
  - semicolon-separated terms with comma decimals, e.g. `1,5; 3; 4,5`
- Accept 2 through 100 terms and use the shared parser's validation messages.
- Submit by keyboard or pointer; an invalid submission keeps the page usable and does not create a chart or history record.
- Every recognized pattern is displayed with its Portuguese rule explanation and next term. Multiple matches are all shown without ranking a winner.
- Unsupported patterns show no next value and no forecast series.

## Chart and Text Alternative

- Render submitted terms and every recognized one-term continuation with a labeled x-axis (`Termo`) and y-axis (`Valor`).
- Distinguish each recognized rule by a visible series label and non-color styling (for example, solid input line and dashed forecast segment with distinct markers).
- The chart canvas has an accessible name and fallback text.
- A semantic table lists each term position, submitted value, and each rule's predicted value; missing values are explicitly labeled rather than inferred.
- Replacing a prediction updates or destroys the previous chart instance to avoid duplicate canvases and handlers.

## History

- Empty history shows a Portuguese empty-state message.
- Valid matched predictions appear in submission order with original input, all rule labels, and next values.
- Invalid or unsupported submissions are excluded.
- History is memory-only for the current page lifetime and is discarded on reload/close; no browser storage or network request is used.

## Documentation

- Local navigation opens Portuguese topics for the four supported pattern families and mathematical ambiguity.
- Every example corresponds to the shared recognizers; documentation explains that finite terms can admit other mathematical continuations.
- The documentation is bundled into the static output and needs no remote service.

## Error and Responsive Behavior

- Display clear Portuguese validation and unsupported-pattern messages without stack traces.
- Respect keyboard focus order and visible focus; controls have programmatic labels.
- At narrow widths, navigation, form, chart, table, and history remain readable without horizontal page overflow.
